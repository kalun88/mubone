States

One state is active at a time, held for as long as its condition is true.

Events

An event fires once, interrupts the running state, then the state resumes.

Reference

Read once. Nothing here changes as you work.

Patterns. solid holds a colour. slow (1.5 Hz) and fast (5 Hz) blink, pulse breathes through eight steps, and flash is the 90 ms blip events use. An event's count is how many times its pattern repeats.

⇄ timbre. The interleaves alternate the row's colour with the live scan timbre instead of with black, so the LED carries two facts at once — muted on white/fast says the output is dead and what you would be hearing. The plain timbre pattern is offered on scan alone: it paints the colour the visualiser gives the particles the cursor would fire from now, and falls back to idle when nothing is in radius.

Rate. Messages per second to the sensor while the row runs. The x-imu3 has no device-side blink, so every edge is a message from here, sharing the radio with inbound data over Wi-Fi. If raw readings start looking glitchy, this column is the first place to look.

Disabling. A disabled state falls back to idle rather than to the firmware's own colour. Disabling idle itself releases the override and hands the LED back to the firmware.

Scale. min and max set where the two ends of a controller’s travel land, in the destination’s own units; γ distributes the travel between them. A destination that curves its own output starts at that number rather than 1 — the paint gate reads γ3. Double-click γ for full travel and the destination’s own curve.

What an address accepts. bang takes no argument — just the address. int n|m is an integer with listed options; float a–b u a range in unit u.

Bangs. Over OSC, send the address with no args. Over MIDI, a bang fires once on press and the matching value-0 release is dropped — so a trigger-mode pedal that sends 127 then 0 produces exactly one action per tap. Note-on fires, note-off is ignored.

Multi-station. Each station listens on its own port — a=7500, b=7510, c=7520 — so a sender addresses a station by port; there is no relay in between.

The chain. Read the axis, fold it if |x| is on, clamp into the input range, bend by the curve, scale into the output range, write the destination. Each row above is one of those steps, in that order.

Two mappings, one destination. The last one written wins, per frame. There is no summing — if two rows fight, disable one.

MIDI and OSC. Both send only on change, at the sensor’s own rate. OSC needs the desktop app; in the browser the row stays but its destination reads electron only.

          What the colours mean
          Colour is the timbre of the sound at that moment, the same on every instrument and every screen: hue is brightness, from deep tones to noise, and saturation is how tonal it is — full colour for a clear pitch, ashen for noise. It is not settable, so a colour means the same thing to you and to whoever you are playing with.

          Match your OS or interface rate to avoid resampling. Chrome prefers 48 kHz.
        

        

          
        

      


      

        

          Buffer size
          Web Audio always renders in a fixed 128-sample quantum; this size reaches only Electron's native multi-channel output.

          Max grains
          How many grains may sound at once, and how many marks may light with them. The engine thins by its own load before this is reached, so raise it for a thicker wash and lower it only on a machine that struggles. Applies at once; anything sounding stops.
        

        

          
          
        

      


      

        

          Stall cushion
          How deep the two hops between the engine and the interface may run: the output queue and the input ring. Latency against stall tolerance — a freeze longer than this is a dropout; shorter cushions are tighter to play against. Applies at once, on any interface.
        

        

          
          
        

      


      

        

          Latency
          The time between a sound and its sample, in and out. The tape engine steers by it: a loop's edges follow your press and release, an overdub lands where you sang it. The estimate comes from the streams; Measure plays six clicks and listens for them — it needs the output to reach the mic (speakers, or a cable). Stored per device pair and rate as the devices' own share, so the buffer and the cushion can change without measuring again.
